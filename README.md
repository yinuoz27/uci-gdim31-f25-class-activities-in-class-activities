# in-class-activities
## Devlogs
### W1
I compare making Unity games to running a restaurant. The scene is where everything happens in the restaurant itself. The game object is the dishes on the menu: players, platforms, gold coins, spikes. The components are the recipes and tools behind each dish. One recipe tells players how to move, and the other makes the gold coins disappear when touched.

### W2
The r, g, b values are decimals between 0 and 1. An int can only store whole numbers. It cannot store 0.5. A bool is only true or false. A string is just text. None of them work for colors.

The bounce count is a whole number. There is no 1.5 bounces. So int is good for counting.

My g -= 0.1f line was missing a semicolon. The error message ("; expected") told me what was missing. Every statement in C# must end with a semicolon.
